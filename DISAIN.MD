# DISAIN — дизайн-система витрины «МебельДом»

Документ описывает оформление публичного каталога мебели: цветовую палитру,
геометрию и типографику через дизайн-токены. Файл дизайн-токенов подключён
один раз в начале `resources/css/app.css` и используется по всему проекту.

## 1. Принципы

- Никаких «магических» цветов прямо в разметке — только CSS-переменные из
  таблицы ниже. Исключение — фирменные градиенты карточек, которые генерируются
  во фронтенде.
- Все карточки, панели, фильтры строятся через токены `--surface`, `--border`,
  `--radius-*`, `--shadow-*`.
- Акцентные действия и активные состояния только через `--accent*`.

## 2. Подключение

Токены объявлены в `:root` в начале `resources/css/app.css`:

```css
:root {
  --bg: #f5f1ea;
  /* ... см. таблицы ниже ... */
}
```

Далее по тексту все переиспользуемые значения ссылаются на эти переменные:

```css
.header { background: var(--surface); }
.card  { box-shadow: var(--shadow); }
```

## 3. Дизайн-токены (CSS-переменные в `:root`)

Определены один раз в начале `styles.css` и используются по всему проекту.
Никаких «магических» цветов в разметке — только через эти токены (кроме фирменных
градиентов карточек, которые генерируются в `products.js`).

### Палитра

| Переменная | Значение | Назначение |
|---|---|---|
| `--bg` | `#f5f1ea` | фон страницы (тёплый кремовый) |
| `--bg-alt` | `#efe9df` | альтернативный фон |
| `--surface` | `#ffffff` | фоны карточек, панелей, фильтров |
| `--text` | `#2c2a26` | основной текст |
| `--text-muted` | `#7d7669` | вторичный текст |
| `--accent` | `#c05a2e` | основной акцент (оранжево-терракотовый) |
| `--accent-dark` | `#a04925` | тёмный акцент (hover, заголовки цифр) |
| `--accent-soft` | `#f7e5d8` | мягкая подложка акцента |
| `--gold` | `#e8c56b` | золотой (тэг hero, рейтинг, границы benefit) |
| `--border` | `#e6ded2` | все бордеры и разделители |
| `--green` | `#4e8a57` | зелёный (маркеры пунктов «Доставка») |

### Геометрия

| Переменная | Значение | Назначение |
|---|---|---|
| `--radius` | `12px` | стандартный радиус (тулбар, инпуты) |
| `--radius-lg` | `18px` | крупный радиус (карточки, панели, свг hero) |
| `--shadow` | `0 8px 24px rgba(74,54,32,.08)` | обычная тень |
| `--shadow-hover` | `0 14px 34px rgba(74,54,32,.14)` | тень при наведении |

### Типографика (по умолчанию)

- Шрифт: `'Segoe UI', system-ui, sans-serif`
- `line-height` базовый: `1.55`; заголовки `1.15–1.35`
- Кегли: маленький/вторичный `12–14px`, базовый `14.5–15.5px`,
  подзаголовки `15–17px`, секционные `21–26px`, крупные `32–44px`

## 4. Классы-компоненты

Публичные страницы каталога используют готовые CSS-классы из
`resources/css/app.css`:

- Герой главной страницы: `.hero`, `.hero__inner`, `.hero__tag`, `.hero__stats`
- Каталог категорий: `.catalog-categories`, `.category-card`
- Список мебели в категории: `.category__layout`, `.catalog`, `.products-grid`,
  `.card`, `.card__image`, `.card__body`, `.card__title`, `.card__price`
- Хлебные крошки: `.breadcrumbs`
- Шапка и подвал витрины: `.header`, `.footer`
