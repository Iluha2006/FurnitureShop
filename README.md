# Мебельный магазин

Инструментальная торговая площадка «ArchiWeb» — онлайн-каталог и интернет-магазин корпусной и мягкой мебели: управление товарным каталогом, корзиной покупателя и оформлением заказов.

## Описание информационной системы

Система автоматизирует основные бизнес-процессы розничной продажи мебели:

- **Каталог товаров** — карточка товара включает название, описание, цвет, цену, остаток на складе, производителя, категорию и подробные технические характеристики (габариты, материалы, тип раскладки, вес, объём упаковки, гарантия).
- **Медиагалерея** — к каждому товару привязано одно или несколько изображений, одно из которых помечено как основное (`is_main`).
- **Корзина покупателя** — привязана к пользователю, хранит набор позиций с количеством и зафиксированной ценой.
- **Заказы** — пользователь оформляет заказ из выбранной мебели; заказ проходит по статусной модели от «нового» до «доставленного» или «отменённого».
- **Справочники** — категории мебели и производители, общие для всего каталога.

## Предметная область сущностей

Система построена на десяти сущностях. Все денежные поля хранятся как `DECIMAL` (не `float`), чтобы исключить ошибки округления; валюта задаётся отдельной строкой (по умолчанию `RUB`).

### Каталог

| Сущность | Таблица | Ключ | Назначение |
|---|---|---|---|
| `FurnitureCategory` | `furniture_categories` | `category_id` | Категория мебели. Заполняется 17 справочными значениями: комоды и тумбы, мебель для детской комнаты, кухни, офиса, ванной, спальни, стеллажи, прихожие, стенки для гостиной, столы, шкафы-купе, раздвижные двери, товары для дома, матрасы, диваны, кресла, пуфы |
| `FurnitureManufacturer` | `furniture_manufacturers` | `manufacturer_id` | Производитель мебели (название и slug) |
| `FurnitureSpecification` | `furniture_specifications` | `id` | Расширенные технические характеристики товара. Все поля nullable: габариты (`width_cm`, `length_cm`, `height_cm`), тип раскладки (`folding_type`), вставка (`insert_type`), материалы (`materials`), поверхность (`surface`), вес (`weight_kg`), объём в упаковке (`package_volume_m3`), гарантия (`warranty`) |
| `Furniture` | `furniture` | `furniture_id` | Товар: название, описание, цвет, цена, остаток на складе. Ссылается на категорию, производителя и характеристики |
| `FurnitureImage` | `furniture_images` | `images_id` | Изображение товара: путь к файлу, признак основного изображения, метки времени |

### Покупки

| Сущность | Таблица | Ключ | Назначение |
|---|---|---|---|
| `Cart` | `carts` | `id` | Корзина покупателя, принадлежит пользователю |
| `CartItem` | `cart_items` | `id` | Позиция корзины: товар, количество, зафиксированные цена и валюта |
| `Order` | `orders` | `id` | Заказ пользователя: статус, итоговая сумма и валюта |
| `OrderItem` | `order_items` | `id` | Позиция заказа: товар, количество, цена и валюта на момент заказа |

Статусы заказа (`App\Enums\OrderStatus`): `pending` → `processing` → `shipped` → `delivered`, либо `cancelled`.

### Связи

- `Furniture` **belongsTo** → `FurnitureCategory`, `FurnitureManufacturer`, `FurnitureSpecification`
- `Furniture` **hasMany** → `FurnitureImage`, `CartItem`, `OrderItem`
- `Cart` **belongsTo** → `User`, **hasMany** → `CartItem`
- `Order` **belongsTo** → `User`, **hasMany** → `OrderItem`
- Наличие нестандартных первичных ключей (`furniture_id`, `images_id`, `category_id`, `manufacturer_id`) учтено в моделях через `$primaryKey`.

## Схема данных

```
furniture_categories (category_id) ─┐
                                   ├──< furniture (furniture_id, category_id, manufacturer_id, specifications_id)
furniture_manufacturers (manufacturer_id) ─┘           │
                                                       ├──< furniture_images (images_id)
furniture_specifications (id) ─────────────────────────┘
                                                       ├──< cart_items ──< carts (user_id) ──< users
                                                       └──< order_items ──< orders (user_id) ──< users
```

## Демонстрационные данные

`db:seed` наполняет систему справочными и тестовыми данными:

- **17 категорий** мебели (`FurnitureCategorySeeder`);
- **9 производителей**;
- **50 товаров** (`FurnitureSeeder`) с реалистичными названиями, ценами и остатками;
- **50 карточек характеристик** — адекватные габариты, материалы, тип раскладки, гарантия под каждый вид мебели;
- **133 сгенерированных SVG-изображения**: имя файла — транслитерация названия товара (например, `divan-modern-tryokhmestnyj-1.svg`), на самом изображении подписаны название и категория.

## Технологии

- **Backend:** Laravel 13 (PHP 8.4), Eloquent ORM, PostgreSQL
- **Frontend:** Inertia.js v3 + React, Vite
- **Качество:** Pest-тесты, Pint (стиль), PHPStan/Larastan (статический анализ)

## Запуск проекта

```bash
composer install
cp .env.example .env            # задать параметры БД
php artisan key:generate
php artisan migrate --seed      # миграции + демоданные
php artisan storage:link        # доступ к изображениям через /storage/...
npm install
npm run dev                     # сборка фронтенда (или npm run build)

php artisan serve               # веб-сервер
```

Изображения мебели доступны по адресу `http://localhost:8000/storage/furniture/<имя-файла>.svg`.
